# Tokenwise

Tokenwise is a token-optimization interface with two focused tools:

- PDF Analyzer converts dense PDF content into structured, token-efficient Markdown.
- Prompt Chat rewrites rough prompts into clearer instructions with less repetition.

## Run locally

```bash
npm install
npm run dev
```

The standalone interactive prototype is also available at `dist/index.html`.

## Current scope

The repository contains the complete responsive frontend. PDF analysis and AI prompt optimization are currently demonstrated in the UI and are ready to be connected to backend endpoints.
